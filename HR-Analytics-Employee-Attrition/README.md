# HR Analytics & Employee Attrition Analysis
**Status: Starter — analysis and Tableau dashboard pending.**

Explore aggregate workforce composition and attrition patterns across departments, roles, tenure, and other available attributes.

**Planned stack:** Python (pandas, NumPy), Tableau, descriptive statistics.

## Workflow
1. Select a public HR dataset and document source/license in `data/README.md`.
2. Add it to `data/` and inspect its schema and data quality.
3. Complete EDA in `notebooks/`.
4. Analyze attrition across available groups and define the attrition-rate denominator.
5. Build a Tableau dashboard and document verified findings.

This is exploratory analysis: associations are not proof of causation. Do not use individual-level predictions for employment decisions.
